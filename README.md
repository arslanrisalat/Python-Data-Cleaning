**Small IMDb Data Cleaning and Analysis Using Python**

📌 Project Overview
This small project focuses on cleaning and analyzing the IMDb dataset using Python. Pandas and NumPy were used for data cleaning and preprocessing, while Matplotlib was used to create graphs and visualize data patterns.

🛠️ Tools & Libraries
- Python – Programming language
- Pandas – Data manipulation and cleaning
- NumPy – Numerical operations
- Matplotlib – Data visualization

🔍 Key Activities
- Handled missing values and duplicate records.
- Cleaned and processed the dataset.
- Performed exploratory data analysis (EDA).
- Created graphs to visualize data patterns and trends.

🎯 Objective
To improve data quality and gain meaningful insights from the IMDb dataset through data cleaning and visualization.

🚀 Skills Gained
Python, Data Cleaning, Pandas, NumPy, Matplotlib, and Exploratory Data Analysis (EDA).
